# Hotel Reservation Cancellation Prediction

## Project Overview
This project predicts whether a hotel reservation will be canceled using XGBoost and advanced machine learning methods.

## Dataset
Hotel Reservations Dataset

Target variable: `booking_status`

- `0` = Not Canceled
- `1` = Canceled

The dataset contains 36,275 hotel reservations with booking-related features.

## Machine Learning Model
XGBoost Classifier

## Evaluation
The model is evaluated using:
- ROC-AUC
- PR-AUC
- Precision
- Recall
- Confusion Matrix

## Methods
- Data preprocessing
- Stratified validation
- XGBoost
- Class imbalance analysis
- Threshold optimization
- Optuna hyperparameter tuning
- SHAP interpretability
- Probability calibration

## Tools
Python, Pandas, Scikit-learn, XGBoost, SHAP, Optuna, Matplotlib
